# 하루 단어

일본어 단어를 공부하고 학습 기록을 이어가는 개인용 단어장입니다.

- **뜻 보기 · Z**: 한국어 뜻을 켜거나 끕니다.
- **읽는 법 보기 · X**: 후리가나와 글자별 한자 설명을 함께 켜거나 끕니다. `Esc`나 설명창의 닫기 버튼으로도 끌 수 있습니다.
- 다음 단어로 넘어가면 뜻과 읽기 도움은 다시 숨겨집니다.

현재 수록된 2,543개 단어의 한자 1,070자(반복 부호 포함)에 한국어 뜻, 글자 구성과 쓰임 정보를 제공합니다. 역사적 어원이 확인된 항목과 자형 구성만 설명하는 항목을 구분합니다. 좁거나 낮은 화면에서는 단어 옆의 설명 열을 스크롤할 수 있습니다.

원문 2,543개 중 표기·읽기·한국어 뜻이 완전히 같은 중복 154개를 책과 DAY 구분 없이 제외하여, 실제 학습·목록에는 2,389개를 표시합니다. 가장 앞선 DAY의 항목을 남기며, 같은 DAY라면 체크북·메인북 순서와 원문 번호로 선택합니다. 뜻이나 읽기가 조금이라도 다르면 유지하고, 앞선 DAY에 같은 표기가 있을 때 “등장한 적 있는 단어”와 이전 DAY·책 이름을 표시합니다. 원본 번호와 과거 학습 기록은 삭제하지 않습니다. [중복 정리 내역](data/duplicate-report.json)은 `node scripts/audit_vocabulary.cjs`로 재생성할 수 있습니다.

사전 자료의 출처와 배포 조건은 [한자 자료 안내](data/kanji-sources/NOTICE.md)에 기록했습니다.
